Hosting

The site is hosted on GitHub Pages, run by GitHub, Inc. (USA). When you open a page, your browser sends GitHub your IP address and ordinary request details, as it would to any web server. GitHub may log these to keep the service running and secure; I don't receive or see those logs. This is in my legitimate interest in publishing a website reliably (Art. 6(1)(f) GDPR). Light or dark mode

If you click the light/dark switch, your choice is stored in your own browser (local storage, key enkitech_theme) so the next page opens the same way. It never leaves your device, and you can delete it by clearing this site's data in your browser.

Links to project sites and GitHub take you to sites with their own privacy policies. Sabura's is on the Sabura site.
