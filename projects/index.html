Projects

Things I work on. Each has its own site with documentation.

  • Sabura

    Whiteboard · free and open source (MIT) · runs in the browser

    A whiteboard that lives in one file. Every board is a single HTML file with the editor built in: open it in any browser, edit it, send it on. No install, no account, no server, and it works offline. AI agents such as Claude can read and edit boards too.

    Visit the Sabura site → Source on GitHub →

  • Athyr

    AI agent runtime · single binary · language agnostic

    A lightweight runtime for running AI agents as distributed microservices. One binary to install; agents stay stateless and can be written in any language, with SDKs for Go and Python.

    Visit the Athyr site → Source on GitHub →
