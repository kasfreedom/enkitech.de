Sabura

A whiteboard that lives in one HTML file. Every board is a single file with the editor built in: open it in any browser, edit it, send it on. No install, no account, no server, and it works offline. AI agents can read and edit boards too.

Free and open source under the MIT licence.

A lightweight runtime for running AI agents as distributed services. You install one binary; agents stay stateless and can be written in any language, with SDKs for Go and Python.
